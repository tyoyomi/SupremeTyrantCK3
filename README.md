# Supreme Tyrant

Crusader Kings III dread / tyranny mod. Version 0.1.0. Supported game version 1.20.*.

Embrace the Supreme Tyrant trait for Absolute Tyranny soft-land, Arbitrary Arrest, Public Execution Spectacle, Crush Dissent, Confiscate Under Dread, Force Oath of Fear, Mass Terror, and a yearly Reign of Terror pulse. Soft peer to Supreme Diplomat (fear twin): terrified yes — not charm, not hooks, not conquest CBs.

Canonical working copy (when Windows is online): `Documents/Development/CK3 Mods/SupremeTyrantCK3/st` (+ outer `st.mod`). GitHub is intended source of truth once `tyoyomi/SupremeTyrantCK3` exists.

Soft peers: Supreme Sovereign, Supreme Schemes, Supreme Diplomat, Death Stare, Exalted Advisor, Succession Unity Soft Glue, Exalted Dynasty/Culture/Faith (detection / tooltips only; no hard dependency).

Prefix: `st_`. Additive only; no `replace_path`. Terror Stare deferred.
